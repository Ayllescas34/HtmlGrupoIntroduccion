Lógica de Sistemas

En la clase de Lógica de Sistemas se abordan los fundamentos esenciales para el análisis y diseño de soluciones informáticas, comenzando con el estudio de proposiciones y tablas de verdad, que permiten representar y evaluar expresiones lógicas. A partir de allí, se profundiza en el álgebra de Boole, herramienta clava en el diseño de circuitos y estructuras de decisión. Además, se trabaja con diagramas de flujo para visualizar procesos lógicos, y se introducen conceptos de programación orientada a objetos (POO) junto con diagramas UML, facilitando la representación estructurada y funcional de sistemas complejos.

Temas de Lógica

En la clase de Lógica de Sistemas se estudian herramientas clave para analizar y diseñar soluciones informáticas, como proposiciones, tablas de verdad, álgebra de Boole, diagramas de flujo, programación orientada a objetos (POO) y diagramas UML.

Tablas de verdad

Las tablas de verdad muestran todas las combinaciones posibles de valores lógicos en una proposición, y ayudan a verificar si una expresión es verdadera o falsa.

Álgebra de Boole

El álgebra de Boole permite simplificar expresiones lógicas usando operaciones como AND, OR y NOT, siendo esencial en lógica digital y estructuras de decisión.

Diagramas UML

Los diagramas UML son representaciones gráficas que muestran la estructura y funcionamiento de un sistema, útiles para modelar software orientado a objetos.

Proyecto

El proyecto consiste en la elaboración de un diagrama de flujo que gestione el control académico de 5 estudiantes. El sistema debe registrar el nombre, las 3 notas de parciales, y la asistencia de cada uno, con un valor total de 20 clases, registrando cuántas clases asistió. Además, el sistema debe calcular el promedio de las notas y verificar el porcentaje de asistencia. Si el promedio es menor a 61 o el porcentaje de asistencia es menor al 75%, el estudiante será marcado como reprobado, de lo contrario, será aprobado. Todo esto debe implementarse utilizando acumuladores (arrays) para manejar los datos de los estudiantes de forma eficiente.

Herramientas

Para llevar a cabo los proyectos y tareas en la clase de Lógica de Sistemas, se utilizaron diversas herramientas software que facilitaron la implementación y simulación de los conceptos aprendidos. Entre ellas, los emuladores de compuertas lógicas fueron esenciales para visualizar y probar circuitos digitales. También se empleó PSeInt, una herramienta para diseñar algoritmos mediante pseudocódigo, que ayudó a estructurar la lógica de los programas. Además, se utilizó Software Dia para crear diagramas de flujo, permitiendo una representación clara y visual de los procesos lógicos en el sistema.
